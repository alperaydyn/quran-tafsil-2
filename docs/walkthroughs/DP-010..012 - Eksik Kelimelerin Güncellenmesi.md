### 2. İstemci On-Demand Zenginleştirme Servisi Oluşturuldu
- [lexiconEnrichmentService.ts](file:///Users/alperaydin/Projects/kuran-tafsil-net/tafsil-ios-app/src/services/lexiconEnrichmentService.ts):
  - `needsEnrichment(data)`: Kelimenin eksik veya asgari seviyede olup olmadığını denetler.
  - `enrichWordOnDemand(word, verse)`:
    - 1. Adım: Tohum ve MMKV önbelleği kontrol eder.
    - 2. Adım: Canlı API'den güncel veriyi çekmeyi dener (`/kelimeler/lexicon?q=...`).
    - 3. Adım: API çevrimdışı ise **Heuristik Dilbilim Motoru (`generateHeuristicLexicon`)** devreye girer:
      - 20'den fazla temel harf, edat, zamir ve bağlaç tablosu (`fî`, `alâ`, `min`, `inne`, `kellâ`, `mâ`, `lâ`, `hüve` vb.)
      - Fiil / İsim morfolojik vezin kestirimi (`fiil · muzari`, `isim · marife`)
      - Ayet meali bağlamından anlam çıkarımı
    - 4. Adım: Üretilen veriyi MMKV önbelleğe (`lex_v1_...`) yazar.
